# BancoDeDados — Sistema de mercado

Resumo curto:

- Repositório com um script SQL (`Sistema_De_banco.sql`) que contém a estrutura e dados de exemplo de um sistema de banco de dados.
- A pasta `img/` contém imagens relacionadas (diagramas, capturas de tela ou material de apoio).

Como usar:

1. Abra seu gerenciador de banco de dados (MySQL, MariaDB, PostgreSQL ou outro compatível).
2. Importe ou execute o arquivo `Sistema_De_banco.sql` para criar as tabelas e popular os dados de exemplo.

Requisitos:

- Um servidor de banco de dados compatível e acesso para executar scripts SQL.

Contato / Observações:

- Este repositório é apenas fins educativos revise o script antes de executar em ambientes de produção.
